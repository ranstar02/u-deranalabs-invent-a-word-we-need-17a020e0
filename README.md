**sockorphan** — *the lone sock left behind when the wash swallows its pair.*

One new English word for a universal little tragedy: every laundry load
seems to swallow exactly one sock, leaving its partner alone in the drawer,
waiting forever for a reunion that never comes. A blend of *sock* + *orphan* —
sayable, spellable, and instantly recognisable the moment you hear it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

`main.py` (Python 3, no dependencies, no network) writes the single-line
entry to `entry.txt` in the output directory (default `/output`).
